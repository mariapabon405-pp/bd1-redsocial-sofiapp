Red Social Pascualina - Modelo Lógico de Base de Datos

## Nombre del Proyecto
Diseño e Implementación de la Base de Datos para la Red Social Estudiantil Pascualina.

## Realizado Por 
* **María Sofía Pabón Pabón** - Grupo G101-Base de Datos

## Descrpción
El proyecto consiste en el diseño de una base de datos relacional orientada a conectar a la comunidad estudiantil de la Institución Universitaria Pascual Bravo. El sistema permite gestionar perfiles académicos, publicaciones, comentarios, grupos de estudio, eventos institucionales, catálogo de habilidades e intereses, interacciones mediante reacciones, red de seguidores y tutorías entre estudiantes (mentorías).

Estructura de Entregables (Tarea 2)
