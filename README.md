## Breve Descripción del Caso
El proyecto consiste en el diseño de una base de datos relacional para la Red Social Estudiantil Pascualina. Permite gestionar perfiles académicos, publicaciones, comentarios, grupos de estudio, eventos institucionales, catálogo de habilidades e intereses, interacciones mediante reacciones, red de seguidores y tutorías entre estudiantes (mentorías).
